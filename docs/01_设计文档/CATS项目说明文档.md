# CATS 项目说明

> 本文是纲领性文档，只定义**目标、边界、分层原则**。
> 平台与实现细节见文末[文档索引](#6-文档索引)。

## 1. 项目目标

在开发机上实现一套 **CANopen（CiA 402）主站**：通过一路 CAN 总线**同时控制两路伺服电机**运动。

硬约束：代码最终要**整体移植到 orin-agx**。orin-agx 侧的 CAN 驱动由他人提供，目前尚未就绪，
因此"可移植"优先于"功能齐全"。

## 2. 系统组成

| 部件 | 说明 |
|---|---|
| 主控 | orin-agx |
| 驱动器 | 雷赛 **2LD2-CAN7020B**，**双轴，共 1 台** |
| 伺服电机 | 雷赛 LVM08008H3G3-M17，2 套 |
| 负载 | 两路电机分别接丝杆滑块机构 |
| 连接 | 主控 ↔ 驱动器：CAN |

一台双轴驱动器在总线上呈现为 **2 个独立的 CANopen 节点**（同型号、同对象字典、共用波特率），
业务上的"轴"对应协议上的"节点"。详见 [2LD2-CAN7020B 双轴驱动器说明](../02_驱动器说明/2LD2-CAN7020B双轴驱动器说明.md)。

## 3. 设计原则

1. **分层优先**：先把边界切对，再谈功能。
2. **单向依赖**：只能外层调用内层，内层不得反向引用外层。
3. **只换壳**：移植到 orin-agx 时，只允许修改"边界层"和"集成层"。
4. **内核平台无关**：内核层不出现 socket、CAN 设备节点、线程、系统时钟等平台 API。
5. **装配集中**：对象创建与依赖注入只有一个地方。

## 4. 分层结构

```text
┌──────────────────────────────────────────────┐
│ 集成层  进程入口 / 对外接口（Qt ↔ lyos 节点） │  可换
├──────────────────────────────────────────────┤
│ 应用层  流程与装配（启动、使能、故障复位、调度）│  少量适配
├──────────────────────────────────────────────┤
│ 轴层    轴集合 / 目标 / 反馈 / 单位换算       │  业务
├──────────────────────────────────────────────┤
│ 设备层  设备 → 轴映射 / CiA 402 语义          │  可移植资产
├──────────────────────────────────────────────┤
│ 内核层  CANopen 协议核心（NMT/SDO/PDO/SYNC…） │  可移植资产
├──────────────────────────────────────────────┤
│ 边界层  SocketCAN 实现（canopen/driver）             │  可换
└──────────────────────────────────────────────┘
                       ↓
              开发机与 Orin-AGX 共用 SocketCAN
```

三圈划分：

| 圈 | 层 | 移植时的动作 |
|---|---|---|
| 内核圈 | 内核层 + 设备层 + 轴层 | **不动**，这是要交付的资产 |
| 边界圈 | 边界层 | 换实现（本机套接字 ↔ 平台驱动） |
| 集成圈 | 应用层 + 集成层 | 换装配方式（本机 Qt 界面 ↔ lyos 节点） |

参考实现：`robot_ecat_driver`（EtherCAT 版）已按同一思路落地——把 SOEM/IGH 收在一个 backend 后面，
内核不 include 任何后端头文件。CATS 把"CAN 收发"收在同类的 backend 后面。
