# 原点标定与回零（2LD2-CAN7020B 台架实测 2026-11-20）

> 结论：当前**无电池盒**、`2015h = 0`（增量模式）⇒ **位置掉电不保存**，每次上电必须标 0 或回零。
> 相关：[2LD2-CAN7020B驱动器配置基准](2LD2-CAN7020B驱动器配置基准.md) · [CAN通信与波特率调试记录](CAN通信与波特率调试记录.md)

## 1. 现状

| 项 | 值 | 说明 |
|---|---|---|
| `2015h` 绝对值编码器设置 | **0** | 增量模式，多圈功能关闭 |
| 电池盒 | **无**（暂时不装） | 编码器线上无电池盒 |

## 2. 回零方式（两种，都实测过）

### 2.1 原点开关回零（`6098h = 21`）—— 主用

**方法 21 = 原点开关 + 不用 Z 信号 + 负向起始**。在 `607Eh = 128` 下，“负向”即**朝近端**（原点开关所在侧）。

| 对象 | 值 | 说明 |
|---|---|---|
| `6060h` | `6` | HM 模式 |
| `6098h` | `21` | 原点开关法 |
| `6099h:01` | `2000` pulse/s | 搜索速度（0.2 圈/s） |
| `6099h:02` | `500` pulse/s | 反向精细速度 |
| `609Ah` | `2000` pulse/s² | 加减速 |
| `607Eh` | `128` | 位置模式反向；PP 与 HM 同时生效 |

`6098h` / `6099h` / `609Ah` 是驱动器侧的持久配置，由
`apps/tools/drive_setup/drive_setup.py` 写入；固件不写这几项，只切模式、发启动。

流程：

```
1. 6060h = 6                          → 回读 6061 确认 = 6
2. 6098h = 21
3. 6099h:01 = 2000   6099h:02 = 500   609Ah = 2000
4. 使能：6040h 06 → 07 → 0F（每步回读 6041）
5. 6040h = 0x1F                       ← 必须全程保持！
6. 等 6041h：bit12=1 完成 / bit13=1 回零出错
7. 6040h = 0x0F，再 0x00 断使能
8. 6060h = 1 切回 PP
```

⚠️ **`6040h` 的 bit4 必须全程保持 1（非标准行为）**

标准 CiA 402 是“上升沿触发”，但这台驱动器是**电平触发**：把 `6040h` 从 `0x1F` 落回 `0x0F`，
回零立刻中止并退回 operation enabled。

实测证据（2026-11-20）：只保持 300 ms 就落回 `0x0F` 时，方法 19/21/23/25/27/29 **全部**只走约
103 个计数就停（= 300 ms × 平均 300 pulse/s，与加减速曲线吻合），`6041` 一直是 `0x8737`；
保持 `0x1F` 不动时回零完整执行。

实测时序（两轴，人手遮挡开关）：

| 时刻 | 轴1 位置 | 轴2 位置 | 事件 |
|---|---|---|---|
| 0 s | −5 | −19307 | 负方向匀速，2000 pulse/s |
| 2.80 s / 7.51 s | −4664 | −33395 | 挡住开关（`60FD` **bit2 = 1**） |
| 3.78 s / 8.52 s | −5586 | −34245 | 减速到最深，开始反向 |
| 5.59 s / 9.53 s | −4774 | −33811 | 拿开遮挡（bit2 = 0） |
| 5.75 s / 9.68 s | **0** | **0** | `6041` = `0x1637`（bit12=1），`6064` 归零 |

- 反向段实测约 **450~500 pulse/s**，与 `6099h:02 = 500` 吻合；减速约 1 s 停住，与 `609Ah = 2000` 吻合
- **零点位置 = 开关释放的那一侧**（不是碰到的那一侧）
- `60FD` 的 **bit25(BRAKE)** 在使能、电机转动时也为 1，含义与手册不符，未查明
- `60FD` 的 **bit24(INP)** 运动中有变化、静止恢复
- **`6041h` bit11 不能用作判据**：这台驱动器在 PP 模式且已使能时该位恒为 1（此时 `60FD` 的 NOT/POT 均为 0，软限位 `607Dh` 也为 0），HM 运动过程中则为 0。回零出错只看 **bit13**

### 2.2 当前位置标零（`6098h = 35`）—— 2026-11-19 实测

1. NMT Start（`0x000`：`01 <node>`）
2. `6060h = 6`（HM 模式）
3. `6098h = 35`（以当前位置为原点）
4. `6099h:01 = 2000`、`6099h:02 = 500`（回零高/低速；方法 35 实际不运动）
5. `609Ah = 2000`（回零加减速）
6. 使能：`6040h` `0x0002` → `0x0006` → `0x0007` → `0x000F`（每步 250 ms）
7. 启动：`6040h = 0x001F` → 50 ms → `0x000F`
8. 等待 `6041h` bit12 = 1（回零完成），读 `6064h` 应为 0
9. 收尾：`6060h = 1`（切回 PP）、`6040h = 0x0000`

**实测（节点1）**：标 0 前 `6064 = 7480` → 标 0 后 `6064 = 0`，`6041 = 0x9737`（bit12=1）✓

> 方法 35 不运动，触发后 50 ms 就落回 `0x0F` 也能完成。但按 §2.1 实测，这驱动器的 bit4 是
> **电平触发**；若哪天发现标零不生效，改成保持 `0x1F` 直到 `6041` bit12 = 1 即可。

## 3. 掉电保持验证 —— **不保持**

- 标 0 后 `6064 = 0` → 断电重启 → `6064 = 7479`（回到单圈角度对应值）
- 结论：**标 0 只在会话内有效，断电丢失**

## 4. 后续方案

### 4.1 当前采用：方案 B —— 主站位置记忆恢复（电池到位前）

**前提（已满足）**：断电时“有抱闸 + 断电后机构不动”。

**原理**：上电后驱动器知道单圈角度 θ（`6064h`），控制器存着上次的绝对位置 A，按最接近 A 的那一圈恢复：

```
abs = round((A - θ) / 10000) × 10000 + θ
```

**主站侧要求**：

- 定期把绝对位置存入非易失存储（如每次运动到位后 + 周期 1 s）
- 上电流程：读 `6064h`（记为 θ）→ 按公式恢复 abs → 后续运动目标按 `目标_驱动器 = 目标_abs - abs + θ` 换算
- **恢复失败判据**：`θ` 与 `A mod 10000` 相差 > 100（考虑 ±10 抖动）⇒ 断电期间被人为转动过 ⇒ 拒绝恢复，要求重新标定

**兜底**：恢复失败或位置不可信时 → 执行 `6098h = 35` 标 0（见 §2）或 HOME 开关回零

### 4.2 后续（电池到位后）：方案 A —— 多圈绝对

1. 装电池盒（对应 LVM 系列编码器线）
2. `2015h = 1`（多圈线性模式）
3. 上电若报 **Er153**（多圈无效，新电池正常现象）
4. 机械回到原点，**断使能**下写 `2015h = 9`（多圈清零）
5. 验证：断电重启 → `6064h` 保持不变
6. `1010h:01 = save` 固化

切换后主站可去掉位置记忆逻辑（或用它做交叉校验）。

## 5. 软件实现（2026-11-23 落地）

| 层 | 位置 | 职责 |
|---|---|---|
| 驱动器配置（脚本） | `apps/tools/drive_setup/drive_setup.py` | 写 `6098` / `6099:01` / `6099:02` / `609A` 并回读校验；**固件不写这些参数** |
| 设备（CiA 402） | `cia402/src/operations/homing.c` | 主流程 4 步：`6060=6` → 回读 `6061` → `6040` 置 bit4 → 轮询 `6041`；中止链另 4 步 |
| 轴 | `controller_axis/axis/axis.c: axis_home()` | 只发 `CIA402_REQ_HOME`，不带任何协议级参数 |
| 业务 | `controller_states/state_homing.c` | `HOLDING` 进、完成后回 `HOLDING`；回零期间原子的——只响应急停与故障，暂停与运动指令丢弃 |

回零参数（`6098h = 21`、`6099h:01 = 2000`、`6099h:02 = 500`、`609Ah = 2000`）
写在驱动器里，由 `drive_setup.py` 负责；主站每拍只做“切模式 → 发启动 → 等结论”。


上层入口：`controller_home()`（全部轴，Qt「回零」按钮）、`controller_home_axis(axis)`
（单轴，`master_probe --home-at <ms> --home-axis 1|2` 调试用）。

收尾链固定为 `6040 → 0x0F` 再 `6060 → 1`：在 HM 模式下带着 bit4 改模式会被当成
PP 的新目标触发，顺序不能反。回零出错（`6041` bit13）与超时都先发 halt 再收尾。

## 6. 备注

- 位置单位：**1 圈 = 10000 指令单位**（运动实测）
- `6064h` 空闲读数抖动 ±10 指令单位
- 回零的 `6040h` bit4 必须全程保持 1（见 §2.1）；方法 21 两轴均已实测通过
