> 结论：当前**无电池盒**、`2015h = 0`（增量模式）⇒ **位置掉电不保存**，每次上电必须标 0 或回零。

## 2. 标 0 流程（`6098h = 35`：当前位置为原点）—— 已实测

1. NMT Start（`0x000`：`01 <node>`）
2. `6060h = 6`（HM 模式）
3. `6098h = 35`（以当前位置为原点）
4. `6099h:01 = 2000`、`6099h:02 = 500`（回零高/低速；方法 35 实际不运动）
5. `609Ah = 2000`（回零加减速）
6. 使能：`6040h` `0x0002` → `0x0006` → `0x0007` → `0x000F`（每步 250 ms）
7. 启动：`6040h = 0x001F` → 50 ms → `0x000F`
8. 等待 `6041h` bit12 = 1（回零完成），读 `6064h` 应为 0
9. 收尾：`6060h = 1`（切回 PP）、`6040h = 0x0000`

**实测（节点1）**：标 0 前 `6064 = 7480` → 标 0 后 `6064 = 0`，`6041 = 0x9737`（bit12=1）✓

## 3. 掉电保持验证 —— **不保持**

- 标 0 后 `6064 = 0` → 断电重启 → `6064 = 7479`（回到单圈角度对应值）
- 结论：**标 0 只在会话内有效，断电丢失**

## 4. 后续方案

### 4.1 当前采用：方案 B —— 主站位置记忆恢复（电池到位前）

**前提（已满足）**：断电时“有抱闸 + 断电后机构不动”。

**原理**：上电后驱动器知道单圈角度 θ（`6064h`），控制器存着上次的绝对位置 A，按最接近 A 的那一圈恢复：

```
abs = round((A - θ) / 10000) × 10000 + θ
```

**主站侧要求**：

- 定期把绝对位置存入非易失存储（如每次运动到位后 + 周期 1 s）
- 上电流程：读 `6064h`（记为 θ）→ 按公式恢复 abs → 后续运动目标按 `目标_驱动器 = 目标_abs - abs + θ` 换算
- **恢复失败判据**：`θ` 与 `A mod 10000` 相差 > 100（考虑 ±10 抖动）⇒ 断电期间被人为转动过 ⇒ 拒绝恢复，要求重新标定

**兜底**：恢复失败或位置不可信时 → 执行 `6098h = 35` 标 0（见 §2）或 HOME 开关回零

### 4.2 后续（电池到位后）：方案 A —— 多圈绝对

1. 装电池盒（对应 LVM 系列编码器线）
2. `2015h = 1`（多圈线性模式）
3. 上电若报 **Er153**（多圈无效，新电池正常现象）
4. 机械回到原点，**断使能**下写 `2015h = 9`（多圈清零）
5. 验证：断电重启 → `6064h` 保持不变
6. `1010h:01 = save` 固化

切换后主站可去掉位置记忆逻辑（或用它做交叉校验）。

## 5. 备注

- 位置单位：**1 圈 = 10000 指令单位**（`6092h:01`）
- `6064h` 空闲读数抖动 ±10 指令单位
