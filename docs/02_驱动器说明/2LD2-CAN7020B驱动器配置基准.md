## 1. 硬件接线

### 1.1 连接器与开关

| 项 | 值 |
|---|---|
| 站号 | 轴1 = **1**，轴2 = **2**（驱动器旋码 `RSC-1/RSC-2` + `SW1/SW2` 高位，主站不改站号） |
| 波特率 | **500 kbps**（拨码 `SW3/SW4`，**断电重启生效**） |
| 终端电阻 | `SW6` = **on** |
| CAN 接线 | `CN6`：1 = CANH、3 = CANL、5 = GND；屏蔽层两端接 PE，不接 GND |
| STO | `STO1+ / STO2+` 接 **24V**（短接） |
| 主电 | 48V（`6079h` 母线电压 ≈ 47~48 V） |
| 缺 STO / 主电的后果 | `6041h` 停在 `0x0400`（Not ready），无法使能 |

### 1.2 输入开关（原点 / 限位）

| 轴 | 原点开关（近端，靠电机） | 限位开关（远端） |
|---|---|---|
| 1（ID=1） | `CN-1` **22 脚 DI5** | `CN-1` **23 脚 DI6** |
| 2（ID=2） | `CN-2` **8 脚 DI5** | `CN-2` **9 脚 DI6** |

- 两轴 DI 共用 `COM_IN`（CN-1 19 脚 / CN-2 5 脚）；DI3~DI6 支持 NPN/PNP，推荐外部控制电源 12~24V。
- DI 的**功能由参数分配**（见 §2）：本机 DI5 = HOME、DI6 = POT。换机时必须配置并复验（§4 步骤 8），不能假设出厂默认。

### 1.3 电机与机械方向

| 项 | 值 |
|---|---|
| 电机型号 | **LVM08008H3G3-M17**（雷赛 LVM 系列，17 位多圈磁编、电池后备；**本机未装电池盒**） |
| 抱闸 | 有（断使能即抱住；`2437h` / `2438h` 见 §2） |
| 方向定义 | 面向出轴看：**正方向 = 逆时针 = 滑台远离电机端**；原点开关在近端 |
| 方向的实现 | `607Eh` = **128**（出厂 0 时正方向朝近端）；**PP 与 HM 同时生效** |
| 位置计数 | `6064h` 与指令同向（正指令 → `6064h` 增大） |

## 2. 参数基线

### 2.1 由主站 / 配置脚本写入（两轴相同）

| 对象 | 含义 | 值 | 备注 |
|---|---|---|---|
| `2403h` | Pr4.03（SI4·DI4） | **0** | 必须**先清空**（同类功能不可重复分配，否则 Err210/211） |
| `2404h` | Pr4.04（SI5·DI5，原点输入） | **0x16** | HOME |
| `2405h` | Pr4.05（SI6·DI6，限位输入） | **0x01** | POT（正向禁止） |
| `2504h` | Pr5.04 驱动禁止设定 | **0** | POT 禁正向 / NOT 禁负向（只核对，通常不改） |
| `607Eh` | 电机运行方向 | **128** | 位置模式反向；覆盖 PP 与 HM |
| `2015h` | Pr0.15 绝对值编码器设置 | **0** | 增量模式（无电池；**掉电位置不保持**） |
| `1010h:01` | 参数保存 | 写 `0x65766173` | 所有写入后必须执行 |

### 2.2 由 `firmware/apps/tools/drive_setup/drive_setup.py` 写入（`--save` 固化）

| 项 | 值 |
|---|---|
| TPDO1 | `1A00` = `6041`:16 + `603F`:16 + `6061`:8；`1800:01` = `0x180`+站号；`1800:05` = 10 ms |
| TPDO2 | `1A01` = `6064`:32 + `606C`:32；`1801:01` = `0x280`+站号；`1801:05` = 10 ms |
| TPDO3 / TPDO4 | 不动（出厂 `0x8000xxxx`，禁用） |
| 回零 | `6098h` = **21**（原点开关法）；`6099h:01` = **100000（50 mm/s）**；`6099h:02` = **4000（2 mm/s）**；`609Ah` = **1000000（500 mm/s²）** |
| 急停 | `605Ah` = **2**（按 `6085h` 减速后自动断使能、抱闸抱住）；`6085h` = **4,000,000** |
| 抱闸 | `2437h` = **100** ms（抱闸延时打开）；`2438h` = **100** ms（等抱闸完全打开） |

- 单位：`6099h` / `6085h` 均为指令单位制，1 圈 = 10000 指令单位，**1 mm = 2000 指令单位（1 圈 = 5 mm）**。
  回零搜索 50 mm/s ≈ **1200 rpm**（电机额定 3000 rpm 的 40%），750 mm 行程最坏约 15 s，刹停距离 2.5 mm。
- 回零速度组（50 / 2 mm/s、500 mm/s²）已实机回零验证通过。
- **`605Ah` 保存后必须断电重启才生效**（未生效时急停停在 Quick stop active，无法再使能）。
- `2437h` / `2438h` 是 **32 位对象**，用 2 字节写会被拒（中止 `0x08000000`）。
- TPDO 禁止时间（`180x:03`）**不写**：轴1 可写、轴2 只读（中止 `0x06010002`），出厂值 2 ms / 10 ms 已够用。
- 传输类型（`180x:02`）保持 `255`；事件定时器独立生效，不依赖 SYNC。

### 2.3 只读识别值

| 对象 | 值 | 含义 |
|---|---|---|
| `1000h` | `0x00020192` | CiA 402 伺服 |
| `6502h` | `0x3002D` | 支持 PP / PV / PT |
| `608Fh:01 / :02` | `131072 / 1` | 编码器内部计数（**不是指令单位**） |
| `6092h:01` | **10000** | 一圈脉冲数（指令单位）⇒ **1 圈 = 10000 指令单位** |
| `6091h:01 / :02` | 1 / 1 | 电子齿轮比 |
| `2023h` / `2024h` | 轴1=1 / 轴2=2；波特率码 = **2** | 站号与波特率核对 |

## 3. 通信与运行时行为（事实）

### 3.1 基本通信

| 项 | 事实 |
|---|---|
| 接口 | SocketCAN，**经典 CAN**（非 FD），500 kbps |
| 心跳 | 两轴各 1 Hz：`0x701` / `0x702`；`7F` = Pre-operational，`05` = Operational |
| **使能前提** | **必须先发 NMT Start**（`0x000`：`01 <node>`）；Pre-op 下 `6041h` 恒 `0x0400`，控制字全被忽略 |
| 使能序列 | `6040h`：`0x0002` → `0x0006` → `0x0007` → `0x000F`（每步 250 ms） |
| 使能确认 | `6041h`：`0x0631` → `0x0633` → `0x8637` |
| 断使能 | `6040h = 0x0000` |
| PP 触发 | 写 `607Ah` → `6040h = 0x001F` → 50 ms → `0x000F` |
| 到位判定 | **只信 `6041h` bit10**；固件不比对 `6064h == 607Ah`（限位静默拒绝也会被判为"到位"） |
| 限位行为 | 向禁止方向的 PP 运动被**静默拒绝**（不动、不报错、不丢使能）；反方向正常 |
| `60FDh` 位 | bit0=NOT、bit1=POT、bit2=HOME、bit4~17=SI1~SI14、bit23=E-STOP、bit24=INP、bit25=BRAKE、bit26/27=探针、bit31=Z |

### 3.2 TPDO

- 出厂 COB-ID 全为 `0x8000_xxxx`（bit31=1，**禁用**）；不写一次 COB-ID 就没有 TPDO 帧。
- 启动/停止：写 `0x180x:01` 的 bit31（`0x0000_0181` 有效 / `0x8000_0181` 停发），运行中写立即生效。
- 映射可改：`0x1A00–0x1A03` 按 CiA 301 四步法（Pre-op 下 `1A0x:00 = 0` → 写条目 → `1A0x:00 = N`）。
- 触发：事件定时器 `0x180x:05` 独立生效（设 N ms 即每 N ms 一帧）；数值变化触发为另一条独立通路。
- 当前 TPDO1 / TPDO2 周期实测 10.0~10.1 ms（两轴一致）。
- **不映射 `60FDh`**：其 bit31 是 Z 信号，轴不动时也在翻转，会以 10 ms 一帧刷屏。

### 3.3 回零（方法 21，原点开关法）

| 项 | 事实 |
|---|---|
| 启动 | `6060h = 6`（HM）→ 使能 `06/07/0F` → `6040h = 0x1F` |
| **`6040h` bit4** | **必须全程保持 1**（电平触发，非标准）：落回 `0x0F` 回零立即中止 |
| 完成判据 | `6041h` **bit12 = 1**；`bit13 = 1` 为回零错误 |
| 结果 | `6064h` 归零；零点 = **开关释放的那一侧** |
| 收尾 | `6040h` → `0x0F` → `0x00`，`6060h = 1` 切回 PP |

### 3.4 急停与抱闸

- 固件急停**只写一帧 `6040 = 0x0002`**：按 `6085h` 减速 → 自动断使能 → 抱闸抱住（`605Ah = 2`）。
- 断使能即抱闸：伺服关闭 → BRK 断开 → 抱闸抱住；急停后 `6041h` = `0x0750`。
- 解除急停不写驱动器；再使能由操作员发起。
- `605A` 全取值（手册）：0=Pr5.06、1=`6084`、2=`6085`、3=`60C6` → 减速后断使能；5/6/7 减速后停在 quick stop（**保持使能**）。出厂 6。

### 3.5 运动中改目标（在线变位）

- 标准 bit4 边沿（`0x1F → 0x0F`）**不能**在运动中改目标：电机跑完旧目标就停。
- 必须写厂商扩展 **`6040h = 0x103F`**（bit12 在线变位）：不停车、直接改走新目标；反向改目标平滑过零。
- 改目标同时改 `6081h` 也是即时生效（按 `6084h` 减速到新速度）。
- `0x103F` 之后 `6041h` bit12 置 1，到位后保持；写一帧 `6040 = 0x0F` 清零（不写不影响后续定位）。
- `0x103F` 是脉冲指令，**不进控制字镜像**（避免 HALT 携带 bit12）。

## 4. 新驱动器配置步骤（按顺序）

1. 按 §1 接线；确认 48V、STO 24V、`SW6=on`；上电
2. `can0` 起 500k：`sudo ip link set can0 up type can bitrate 500000 restart-ms 100`
3. 确认两轴心跳 `0x701` / `0x702`
4. SDO 核对只读值（§2.3）与站号/波特率（`2023h` / `2024h`）
5. 写输入分配（**顺序不可颠倒**）：`2403h = 0` → `2404h = 0x16` → `2405h = 0x01`
6. 写方向：`607Eh = 128`
7. 保存：`1010h:01 = 0x65766173`
8. **断电重启**；回读 `2403h/2404h/2405h/607Eh` 确认保留
9. 停掉所有占用 CAN 的程序，跑 `python3 apps/tools/drive_setup/drive_setup.py --save`，再 `--check` 复验 TPDO 与回零参数
10. 按压开关复验：近端 → `60FD` bit2（HOME）；远端 → `60FD` bit1（POT）
11. NMT Start → 使能 → 两轴各 PP 正转 1 圈（10000 指令单位）→ 确认位移与转向
12. 各轴回零一次（方法 21：挡原点开关 → 减速反向 → 松开处标零）

## 5. 验收标准

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 通信 | 两轴心跳 1 Hz；无 BUS-OFF、无错误帧 |
| 2 | 识别值 | `2023h` = 1/2；`2024h` = 2；`1000h`/`6502h`/`608Fh`/`6092h` 与 §2.3 一致 |
| 3 | 参数 | `2403h`=0、`2404h`=0x16、`2405h`=0x01、`607Eh`=128，断电重启后保留 |
| 4 | 输入 | 近端按压 → HOME 置位；远端按压 → POT 置位；释放即复位 |
| 5 | 使能 | NMT 后 `0x02→0x06→0x07→0x0F` 全通，`6041h` 依次 `0x0631→0x0633→0x8637` |
| 6 | PP 点动 | 1 圈位移 = 10000 指令单位（±10），约 5 s，bit10 到位，`603Fh`=0 |
| 7 | 方向 | 正方向 = 面向出轴逆时针 = 滑台远离电机 |
| 8 | 限位 | 限位按住时向该方向运动被拒绝（位移≈0）；反方向正常 |
| 9 | 回零 | 方法 21：挡开关后减速反向、松开处标零；`6041h` bit12=1，`6064h`=0 |
| 10 | TPDO | `drive_setup.py --check` 通过；TPDO1/2 周期 10±0.1 ms |

## 6. 已知限制（事实）

- **掉电位置不保持**：无电池盒、`2015h = 0`；每次上电 `6064h` = 单圈角度换算值，需重新回零（或主站记忆恢复）
- **近端无硬限位**：`607Dh:01/02` 实测为 0，软限位未生效，负向越程无保护
- **`6064h` 空闲抖动 ±10 指令单位**（≈0.1% 圈），对位以物理标记为准
- **1M 波特率未验证可用**，固定用 500k；拨码改动后必须断电重启
- 节点1 `Pr4.00`（SI1）= `0x83`（不在手册功能码表内，节点2 为 0），暂不处理
