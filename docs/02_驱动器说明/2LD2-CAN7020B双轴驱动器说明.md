# 2LD2-CAN7020B 双轴驱动器说明

> 依据：[2LD2-CAN 系列用户使用手册 V1.6](2LD2-CAN系列(7030,7020,7015)用户使用手册V1.6_2987500915933462.pdf) 第 3 章（3.3 / 3.4 接线、3.11 旋码开关、3.12 拨码开关）、
> 实机面板标识、厂商答复。
> 目的：确定主站侧「设备 / 节点 / 轴」三者的关系。
> 返回：[CATS 项目说明](../01_设计文档/CATS项目说明文档.md)

## 1. 结论

**1 台 2LD2-CAN7020B = 2 个独立的 CANopen 节点。**

- 两个轴各自拥有**一套完整且相同**的对象字典；
- 两轴**共用**同一个 CAN 接口与同一个波特率；
- 主站按**节点号**分别控制两轴 ⇒ 业务概念上的"轴"，在协议上就是一个"节点"。

## 2. 面板标识：逐轴 vs 共用

| 项 | 轴 1 | 轴 2 | 性质 |
|---|---|---|---|
| ID 旋码 | RSC-1 | RSC-2 | **各自独立** |
| 调试口 | RS232-1 | RS232-2 | 各自独立 |
| 编码器 | ENC-1 | ENC-2 | 各自独立 |
| IO | CN-1 | CN-2 | 各自独立 |
| 电机输出 | U1 / V1 / W1 + PE | U2 / V2 / W2 + PE | 各自独立 |
| 通讯接口（CAN）、波特率/终端电阻拨码、主回路电源、再生电阻、STO | — | — | **两轴共用** |

图纸位置：手册 3.2「伺服驱动器各端子分布」；电机输出端子详见 3.3 / 3.4。

## 3. 站号设置

- 每轴一个 **ID 旋码**：`RSC-1` / `RSC-2`，对应地址低 4 位（0~15，手册 3.11 表）。
- 拨码块中 `SW1` / `SW2` 分别为 **CAN_ID1 / CAN_ID2 的地址高位选择**（手册 3.12）。
- 波特率与终端电阻两轴共用（`SW3` / `SW4` 选波特率，`SW6` 终端电阻，`SW5` 保留）。
- 本项目的用法：两轴站号直接取 **1** 和 **2**，其余细节不再展开。

## 4. 主站视角的 COB-ID 推导

| 对象 | 轴 1（n=1） | 轴 2（n=2） |
|---|---|---|
| NMT 模块控制（广播） | `0x000` | `0x000` |
| SYNC（广播） | `0x080` | `0x080` |
| EMCY | `0x081` | `0x082` |
| TPDO1 / RPDO1 | `0x181` / `0x201` | `0x182` / `0x202` |
| SDO 客户 → 服务器 / 服务器 → 客户 | `0x601` / `0x581` | `0x602` / `0x582` |
| 心跳 / 节点错误控制 | `0x701` | `0x702` |

- 端口能力：手册 `5004h` —— RPDO 个数 0~4（默认 1）、TPDO 个数 0~2（默认 1）；
  默认长度 RPDO 8 字节、TPDO 17 字节。
- 每个节点的对象字典完全相同 ⇒ **两轴可以用同一份配置模板，只有站号不同**。

## 5. 注意

- 手册 8.2.1 的拨码表（SW1/SW2 = 波特率、SW3 = 终端电阻、SW4 = 地址高位）是**单轴产品的写法**，
  与实机不符，**以第 3 章和面板标识为准**。
- 手册内两处出厂默认值不一致（站号：`Pr0.23` 标"默认 16"与"出厂 2"；波特率：标"默认 1MHz"与
  "出厂值 1 = 800kHz"），上机时以实读为准。

## 6. 对分层的含义

| 层 | 影响 |
|---|---|
| 设备层 | **没有"双轴"特例**，按"同型号节点 × N"统一处理 |
| 轴层 | 只维护「轴 → 节点号」映射 |
| 配置 | 两个节点共用一份模板，仅站号不同 |

## 7. 停机行为（手册 5.1.3 / 605A / 605D）

手册 5.1.3 对象字典：`605A` Quickstop 代码初始值 **6**，范围 0–7；`605D` Halt 减速停止代码初始值 **1**。

`605AH` 条目（pp 模式）原文：

| 值 | 行为 |
|---|---|
| 0 | 通过 pr5.06 选择电机停止后，switch on disable 状态，断使能 |
| 1 | 通过 6084 减速停止后，switch on disable 状态，断使能 |
| 2 | 通过 6085 减速停止后，switch on disable 状态，断使能 |
| 3 | 通过 60C6 减速停止后，switch on disable 状态，断使能 |
| 5 | 通过 6084 减速停止后，**quick stop 状态** |
| **6（出厂）** | 通过 **6085** 减速停止后，**quick stop 状态** |
| 7 | 通过 60C6 减速停止后，quick stop 状态 |

结论：

- **急停（6040 bit2 = 0 → `0x0002`）出厂行为 = 按 6085 急停减速度停下，停在 quick stop 状态，不断使能**（功率级仍通电）。
- **暂停（6040 bit8 = 1 → `0x010F`）出厂行为 = 按 6084 减速度停下，回到 operation enabled，保持使能**（对应 `605D = 1`）。
- 手册没有给出"如何退出 quick stop 状态"的转移表（402 状态机是图，文本层无内容），主站侧按标准 CiA 402 自行处理。

## 8. 主站侧的急停与暂停决策（本项目）

| 动作 | 主站做什么 | 不做什么 |
|---|---|---|
| 急停 | 每轴向 `6040` 写一次 `0x0002`，确认这一笔写有应答 | 不读 `6041`、不等减速过程、不写 `0x0000` 断使能、失败不重试 |
| 解除急停 | 每轴向 `6040` 写一次 `0x000F`（转移 16），让驱动器回可操作；控制器回 `IDLE` | 不读 `6041` 判断驱动器原来停在哪 |
| 暂停 | 写 `6040 = confirmed \| 0x0100`，等 `6041` bit10 到位，再清 bit8 | 不断使能 |

- 急停写失败只报 `CONTROLLER_FAULT_ESTOP_FAILED`，驱动器侧 abort 码通过
  `controller_axis_abort()` 读取；**急停后驱动器仍在使能状态**，这是有意的设计选择。
- **解除急停会让驱动器重新带电使能**，而控制器自己回 `IDLE`（它认为未使能）：这段窗口里
  两者状态不一致，之后按"使能"时 `ENABLING` 读到 `0x0027` 会直接判成功进 `HOLDING`。
- 若以后需要"急停后断电"，把 `605A` 改成 1/2/3，或由主站另写 `6040 = 0x0000`。
