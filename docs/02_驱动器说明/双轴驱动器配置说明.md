# 双轴驱动器配置说明

## ID配置
ID分为1和2，由驱动器自行配置，无需更改任何参数。后续如果提到电机1就代表ID=1.
## 电机及滑台的安装
顺着电机的出轴方向看过去：**正向运动 = 滑台远离电机端**，原点开关在近端（靠近电机）。

方向由驱动器参数 `607Eh` 决定：

| `607Eh` | 正向运动 |
|---|---|
| `0`（出厂） | 滑台朝**近端** |
| **`128`**（本机基准） | 滑台朝**远端** |

- bit7（`128`）在手册里属“位置模式”，**同时覆盖 PP 与 HM**：改一个值就把点到点运动与回零的方向一起翻过来。
- `6064h` 的数值变化方向与指令一致（`+mm` → `6064h` 增大），到位判据 `6064h == 607Ah` 成立。
## 原点和限位

原点/限位接在驱动器本体的控制信号端子上（两轴各一个连接器）：

| 轴 | 连接器 | 原点 | 限位 |
|---|---|---|---|
| 电机1（ID=1） | CN-1（28 脚） | 22 脚 = DI5，数字输入信号 5（原点） | 23 脚 = DI6，数字输入信号 6（限位） |
| 电机2（ID=2） | CN-2（14 脚） | 8 脚 = DI5，数字输入信号 5（原点） | 9 脚 = DI6，数字输入信号 6（限位） |

- 依据：手册 §3.8「控制信号端子连接」引脚表。CN-1 / CN-2 脚号不同只是连接器规格不同（28 脚 vs 14 脚），DI5 / DI6 的功能定义一致。
- 两轴 DI 共用 `COM_IN`（CN-1 19 脚 / CN-2 5 脚）；DI3~DI6 支持 NPN/PNP，推荐外部控制电源 12~24V（手册 §3.9）。
- 默认功能：DI3 = 使能、DI4 = 报警清除、DI5 = 原点、DI6 = 限位（手册 §3.8）。
- 这两路是**驱动器本地 IO**：原点供回零使用（手册 §6.4 原点模式 / `6098h`）；限位在驱动器内部参与驱动禁止（`Pr5.04` / `2504h` POT/NOT），回零模式下是否无效由 `5012-04` bit0 设置。主站侧不接线、不直接读引脚。
- 注意：DI3~DI6 支持"输入功能自定"，若现场改过 DI 功能参数，引脚语义会变，主站不能默认上述默认功能。
