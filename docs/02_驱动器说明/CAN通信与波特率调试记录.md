> 日期：2026-11-19
> 对象：台架上的 2LD2-CAN7020B 双轴驱动器（两轴电机均已接）+ PEAK PCAN-USB Pro FD（`can0`）
> 目的：确认主站侧 CAN 链路可用、确认驱动器实际波特率与站点配置
> **配置基准值与操作步骤以 [驱动器配置基准](驱动器配置基准.md) 为准**；本文件只保留排查过程与证据
> 相关：[双轴驱动器配置说明](双轴驱动器配置说明.md) · [2LD2-CAN7020B 双轴驱动器说明](2LD2-CAN7020B双轴驱动器说明.md) ·
> 手册：[2LD2-CAN 系列用户使用手册 V1.6](2LD2-CAN系列(7030,7020,7015)用户使用手册V1.6_2987500915933462.pdf)

## 1. 结论摘要

| # | 结论 | 证据 |
|---|---|---|
| 1 | **总线基准波特率 = 500 kbps**，两轴一致 | 拨码 `SW3/SW4` 在 500k 档；两轴 `2024h` 都自报 **2**；500k 下 `0x701`/`0x702` 心跳与全部 SDO 正常 |
| 2 | 两轴波特率**不存在分裂** | 同一拨码档位、同一 `2024h` 值，同一速率下可同时通信（2026-11-20 复核） |
| 3 | 初始 `6041h = 0x0400`（Not ready）**根因是未发 NMT Start**，不是硬件故障 | NMT Start 后 `6041h` 立即变 `0x0650`（详见配置基准 §3） |
| 4 | 1M / 250k / 125k 都不是本项目的工作速率 | 基准只用 **500k**；改速率必须两轴同档位、且断电重启后生效 |

> 早期记录里的「节点 1 = 250k、节点 2 = 125k」结论**已作废**：2026-11-20 逐轴复核，两轴均为同一拨码档位、`2024h` 均为 2、500k 下同时正常通信。

## 2. 环境与工具

- 适配器：PEAK **PCAN-USB Pro FD**（双通道，`can0`/`can1` 都在，实测接在 `can0`）
- 驱动：SocketCAN（`peak_usb`），经典 CAN 模式；`python-can 4.3.1`、`candump/cansend` 可用
- 本机无免密 sudo ⇒ 拉起/切换接口需人工执行
- 驱动器侧：`SW6` 终端电阻常 **on**；拨码改动后**必须断电重上电才生效**

## 3. 波特率与节点参数实测

### 3.1 波特率（两轴一致）

| 项 | 轴 1 | 轴 2 |
|---|---|---|
| 拨码 `SW3/SW4` | 500k 档 | 500k 档（两轴共用） |
| `2024h` 波特率码 | **2** | **2** |
| 实际通信 | 500k 正常 | 500k 正常 |
| 心跳 `0x701` / `0x702` | 1 Hz | 1 Hz |

`2024h = 2` 与拨码的 500k 档一致；拨码改动后必须断电重上电才生效。

### 3.2 各节点自报参数

| 读数 | 节点 1 | 节点 2 |
|---|---|---|
| `2023h` 站号 | 1 | 2 |
| `2024h` 波特率码 | 2 | 2 |
| `1000h` 设备类型 | 0x00020192 | 0x00020192 |
| `6502h` 支持模式 | 0x3002D（含 PP / PV / PT） | 0x3002D |
| `608Fh:01/02` 编码器 | 131072 / 1（编码器计数，不是指令单位） | 131072 / 1 |
| `6060h` 目标模式 | 1（PP） | 1（PP） |
| `6041h` 状态字 | **0x0400 = Not ready to switch on** | **0x0400 = Not ready to switch on** |
| `603Fh` 故障码 | 0 | 0 |
| `6064h` 实际位置（读数时刻） | 5346 | 373 |

> 上表 `6041h = 0x0400` 是**未发 NMT Start** 时的读数，属正常现象。

## 4. 位定时与 1M 的历史记录（当前不使用）

- 500k 下 SocketCAN 自动选的采样点约 **87.5%**，与常规 CANopen 设备一致，**不需要手工指定**。
- 1M 当初从未成功（发帧无 ACK → BUS-OFF）。本项目基准就是 500k，没有上 1M 的需求，不再追查。
- 若确实需要强制采样点：iproute2 不允许 `bitrate + sample-point + tq` 同时给，
  改用原始定时 `tq <ns> prop-seg <n> phase-seg1 <n> phase-seg2 <n> sjw <n>`。

## 5. 常用命令（本机）

```bash
# 拉起/切换波特率（需 root；BUS-OFF 后重跑即可恢复）
sudo ip link set can0 down && sudo ip link set can0 up type can bitrate 500000 restart-ms 100

# 被动监听（含心跳 0x701/0x702）
candump can0

# 查看状态与错误计数
ip -details -statistics link show can0
```

- 排障要点：**发一帧看是否 BUS-OFF** = 判断"有没有节点在正确速率上做 ACK"的最快方法

## 6. 变更速率时的步骤

1. 拨码 `SW3/SW4` 改到目标档（两轴共用，一次改好）
2. `can0` 用同一速率拉起
3. **断电重上电**（拨码只在**上电时**生效）
4. 读回 `2024h` 与两轴心跳，确认两轴一致后再继续

台架基准**不写** `2024h`，一律以拨码为准；若确实要改存储值，写后必须 `1010h:01 = 0x65766173` 保存再断电，
失联时可用 RS232 + Motion Studio 改回。
