# 驱动器配置基准（2LD2-CAN7020B，台架实测 2026-11-19）

> 用途：**新驱动器 / 新电机的配置基准**。按 §4 步骤操作，结果必须满足 §5 验收标准。
> 本文件只写"做什么、做到什么值"；原因与排查过程见 [CAN通信与波特率调试记录](CAN通信与波特率调试记录.md)。

## 1. 硬件基线

| 项 | 基准 |
|---|---|
| 站号 | 轴1 = **1**，轴2 = **2**（驱动器旋码设置，主站不改） |
| 波特率 | **500 kbps**（拨码 SW3/SW4 对应档位，**上电生效**） |
| 终端电阻 | SW6 = **on** |
| CAN 接线 | CN6：1=CANH、3=CANL、5=GND；屏蔽层两端接 PE，不接 GND |
| STO | STO1+ / STO2+ 接 **24V**（短接） |
| 主电 | 48V 常上；`6079h` 母线电压 ≈ 47~48 V |
| STO/主电缺失的后果 | `6041h` 停在 `0x0400`，无法使能 |

| 轴 | 原点开关（近端，靠电机） | 限位开关（远端） |
|---|---|---|
| 1 | CN-1 **22 脚 DI5** | CN-1 **23 脚 DI6** |
| 2 | CN-2 **8 脚 DI5** | CN-2 **9 脚 DI6** |

方向约定：**正方向 = 滑台远离电机端**（原点开关在近端）。由 `607Eh = 128` 实现：
出厂值 `0` 时正方向朝近端，写 `128` 翻转为朝远端，**PP 与 HM 同时生效**。
`6064h` 的数值变化方向与指令一致（`+mm` → `6064h` 增大）。
**固件不做 `6064h == 607Ah` 的比对**：PP 到位只看 `6041h` bit10（驱动器自己的
到位决定，含它自己的窗口与滤波）；位置由 TPDO 反馈另行提供，只用于显示。

## 2. 驱动器参数基准（两轴相同）

| 对象 | 参数 | 基准值 | 说明 |
|---|---|---|---|
| `2023h` | Pr0.23 站号 | 轴1=1 / 轴2=2 | 旋码决定，只读核对 |
| `2024h` | Pr0.24 波特率码 | **2** | 2 = 500k，只读核对 |
| `2403h` | Pr4.03（SI4·DI4） | **0** | 空（不能与其它输入重复 HOME） |
| `2404h` | Pr4.04（SI5·DI5，原点输入） | **0x16** | HOME 回零基准 |
| `2405h` | Pr4.05（SI6·DI6，限位输入） | **0x01** | POT 正向禁止 |
| `2504h` | Pr5.04 驱动禁止设定 | **0** | POT 禁正向 / NOT 禁负向 |
| `607Eh` | 电机运行方向 | **128** | 位置模式反向；**PP 与 HM 同时生效**；出厂 `0` |
| `2015h` | Pr0.15 绝对值编码器设置 | **0** | 增量模式（无电池盒；**掉电位置不保持**） |
| `1010h:01` | 参数保存 | 写 `0x65766173` | 修改参数后必须执行 |

只读基线（用于识别驱动器）：

| 对象 | 基准值 | 含义 |
|---|---|---|
| `1000h` | `0x00020192` | CiA 402 伺服 |
| `6502h` | `0x3002D` | 支持 PP/PV/PT |
| `608Fh:01 / :02` | `131072 / 1` | 编码器内部计数（**不是指令单位**） |
| 换算 | **1 圈 = 10000 指令单位** | 运动实测：命令 2 圈 = 20000 指令单位，`6064h` 增量 19921 / 19997 |
| 位置单位 | 指令单位（非编码器计数） | `6064h` / `607Ah` / `6081h` 均用此单位 |

## 3. 主站通信基准

| 项 | 基准 |
|---|---|
| 接口 | SocketCAN，**经典 CAN**（非 FD），500k |
| 心跳 | 两轴各 1 Hz：`0x701`/`0x702`；`7F`=Pre-op，`05`=Operational |
| **使能前提** | **必须先发 NMT Start**（`0x000`：`01 <node>`），否则 `6041h` 恒 `0x0400` |
| 使能序列 | `6040h`：`0x0002` → `0x0006` → `0x0007` → `0x000F`（每步 250 ms，读回 `6041h`） |
| 使能确认 | `6041h`：`0x0631`（准备启动）→ `0x0633`（启动）→ `0x8637`（允许操作） |
| 断使能 | `6040h = 0x0000` |
| PP 触发 | 写 `607Ah` 目标 → `6040h = 0x001F` → 50 ms → `6040h = 0x000F` |
| 点动基准 | `6081h = 2000` 指令单位/s（1 圈/5 s），`6083h = 6084h = 2000` |
| 到位判定 | `6041h` bit10 = 1；`603Fh = 0` |
| 限位生效判定 | 以**实际运动被拒绝**为准（`6041h` bit11 不可靠） |

### 3.1 从站的 TPDO：出厂状态、触发机制、配置方法

**出厂默认**（两轴一致，2026-11-23 实读）：四路 TPDO 的 COB-ID 全部是 `0x8000_xxxx`，
即 **bit31 = 1、全部禁用**。不写一次 COB-ID，永远不会有 TPDO 帧。

| TPDO | 出厂映射 | 长度 | 出厂禁止时间 | 传输类型 |
|---|---|---|---|---|
| TPDO1 | `6041h` 状态字 (16) | 2 | `20` = 2 ms | `0xFF` |
| TPDO2 | `6041h`(16) + `6064h`(32) + `6061h`(8) | 7 | `100` = 10 ms | `0xFF` |
| TPDO3 | `6064h`(32) + `606Ch`(32) | 8 | `100` = 10 ms | `0xFF` |
| TPDO4 | `6064h`(32) + `60FDh`(32) | 8 | `100` = 10 ms | `0xFF` |

**启停**：写 `0x180x:01` 的 bit31。`0x0000_0181` = 有效、`0x8000_0181` = 停发。
**运行中写入立即生效**，不需要 NMT 切换。

**映射可写**：`0x1A00–0x1A03` 按 CiA 301 四步法可改（Pre-operational 下
`1A0x:00 = 0` → 写条目 → `1A0x:00 = N`），两轴实测通过。

**触发机制（两轴实测）**：

| 机制 | 行为 |
|---|---|
| 事件定时器 `0x180x:05` | **独立生效**：设 N ms 就严格每 N ms 一帧；设 0 停发。不需要 SYNC |
| 数值变化 | 另一条独立通路：定时器为 0 时，映射对象一变就发帧 |
| 禁止时间 `0x180x:03` | 只限制最大发送速率，不影响定时器 |
| 参数生效时机 | 运行中写就在运行中生效（定时器 10→50 ms 实测立刻变） |

**禁止时间：轴 1 可写、轴 2 只读**（abort `0x06010002`）⇒ 配置不能依赖改它。
出厂值 `2 ms`（TPDO1）/ `10 ms`（TPDO2~4）已经够用：TPDO2 禁止时间 = 10 ms
正好把变化触发的速率压到与定时器一致，实际就是每 10 ms 一帧。

**当前台架配置**（由 `apps/tools/drive_setup` 写入，并已用 `1010h:01` 保存，2026-11-23）：

| TPDO | 映射 | COB-ID | 事件定时器 | 长度 |
|---|---|---|---|---|
| TPDO1 | `6041h`(16) + `603Fh`(16) + `6061h`(8) | `0x181` / `0x182` | 10 ms | 5 |
| TPDO2 | `6064h`(32) + `606Ch`(32) | `0x281` / `0x282` | 10 ms | 8 |
| TPDO3 / TPDO4 | 不动 | 不动（出厂禁用） | — | — |

实测周期中位 10.0~10.1 ms（两轴一致）。`60FDh` 不再映射：它的 bit31 是 Z 信号，
轴不动时也在翻转，走“变化即发”会以 10 ms 一帧刷屏。

**保存**：驱动器的 `1010h:01` 可写，两轴均实测接受。台架已保存，掉电重启后配置仍在；
换方案或排障时重新跑一遍 `drive_setup.py`（幂等）再 `--save` 覆盖即可。
写 `1010h:01` 时 EEPROM 操作会占住驱动器约 100 ms，期间 TPDO 周期会被拉长，写完自动恢复。

### 3.2 回零（原点开关法，`6098h = 21`，两轴实测 2026-11-20）

| 项 | 基准 |
|---|---|
| 方法号 | `6098h = 21`（原点开关 + 不用 Z 信号 + 负向起始） |
| 速度 | `6099h:01 = 2000`（搜索）、`6099h:02 = 500`（反向）、`609Ah = 2000`（加减速） |
| 写入方式 | **驱动器侧持久配置，由 `apps/tools/drive_setup` 写入；固件不发这些写请求** |
| 启动 | `6060h = 6`（HM）→ 使能 `06/07/0F` → `6040h = 0x1F` |
| **`6040h` bit4** | **必须全程保持 1**；一旦落回 `0x0F` 回零立刻中止（**非标准电平触发**，见§6） |
| 完成判据 | `6041h` **bit12 = 1**（完成）；**bit13 = 1**（回零错误） |
| 结果 | `6064h` 归零；零点位置 = **开关释放的那一侧** |
| 收尾 | `6040h` → `0x0F` → `0x00`，`6060h = 1` 切回 PP |

两轴行为完全一致（同方法号、同速度、同方向）。完整时序与实测数据见
[原点标定与回零流程](原点标定与回零流程.md)。

## 4. 新驱动器配置步骤（按顺序执行）

1. 按 §1 完成接线；确认 48V 主电、STO 24V、SW6=on
2. 上电；`can0` 以 500k 启动；确认两轴心跳 `0x701`/`0x702` 都在
3. SDO 读取并核对：`2023h`、`2024h`、`1000h`、`608Fh`、`6502h`、`6079h`（对照 §1/§2）
4. 按顺序写参数（**不可颠倒**）：
   - `2403h` ← `0`
   - `2404h` ← `0x16`
   - `2405h` ← `0x01`
5. 写 `1010h:01 = 0x65766173`（保存）
6. **断电重启**
7. 回读 `2403h`/`2404h`/`2405h`，确认仍为 `0 / 0x16 / 0x01`
8. 跑 `python3 apps/tools/drive_setup/drive_setup.py`（写 TPDO 反馈通道与回零参数，自带回读校验），
   再用 `--check` 复验一次
9. 按压开关复验：近端 → `60FD` bit2（HOME）；远端 → `60FD` bit1（POT）
10. NMT Start → 使能序列 → 两轴各 PP 正转 1 圈 → 记录 `6064h` 增量与转向
11. 按 §3.2 各回零一次：挡原点开关 → 减速反向 → 松开 → `6041h` bit12=1、`6064h`=0

## 5. 验收标准

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 通信 | 两轴心跳 1 Hz；无 BUS-OFF、无错误帧 |
| 2 | 站号/波特率 | `2023h` = 1/2；`2024h` = 2 |
| 3 | 参数保存 | `2403h`=0、`2404h`=0x16、`2405h`=0x01，断电重启后保留 |
| 4 | 输入复验 | 近端按压 → HOME 置位；远端按压 → POT 置位；释放即复位 |
| 5 | 使能 | NMT 后 `0x02→0x06→0x07→0x0F` 全通，状态依次 `0x0631→0x0633→0x8637` |
| 6 | PP 点动 | 1 圈位移 = **10000 指令单位**（±10），用时约 5 s，bit10 到位，`603Fh=0` |
| 7 | 方向 | 正方向 = 面向出轴逆时针 = 滑台远离电机 |
| 8 | 限位 | 限位按住时向该方向运动被拒绝（位移≈0）；反方向正常 |
| 9 | 回零 | 方法 21：挡开关后减速反向、松开处标零；`6041h` bit12=1，`6064h`=0 |

## 6. 已知事项

- **指令单位换算**：1 圈 = 10000 指令单位（运动实测）；`608Fh`（131072）仅编码器内部计数，**勿混用**
- **`6064h` 空闲读数抖动 ±10 指令单位**（≈0.1% 圈），对位/对齐以物理标记为准
- **限位行为**：按住限位时，向该方向的 PP 运动被**静默拒绝**（不动、不报错、不丢使能）；反方向正常
- **到位判定只信 `6041h` bit10**：固件不比对 `6064h` 与 `607Ah`。因此**被限位静默拒绝的
  运动会被判为到位成功**——界面上位置不动，但状态回到 `HOLDING`。需要识别这种情况时，
  只能靠人看位置或外部行程保护，固件不做核对
- **`60FDh` 位定义**（手册）：bit0=NOT、bit1=POT、bit2=HOME、bit4~17=SI1~SI14、
  bit23=E-STOP、bit24=INP、bit25=BRAKE、bit26/27=探针1/2、bit31=Z 信号
- **回零**：**方法 21**（原点开关法）两轴均已实测（见 §3.2）；方法 35（当前位置标零）也可用。
  **掉电不保持**，每次上电需重新回零
- **波特率固定 500k**：拨码 `SW3/SW4` 500k 档 + `2024h` = 2（两轴一致）；改拨码后**必须断电重启**才生效
- **回零的 `6040h` bit4 是电平触发**（非标准）：必须在整个回零过程保持为 1，落回 `0x0F` 会立即中止回零（2026-11-20 实测，见 §3.2）
- **近端无硬限位**：`607Dh:01/02` 实测两轴均为 **0**，软件限位**没有生效**，负向越程目前无任何保护
- 节点1 `Pr4.00`（SI1）= `0x83`（不在手册功能码表内，节点2 为 0），未处理
