# 驱动器配置基准（2LD2-CAN7020B，台架实测 2026-11-19）

> 用途：**新驱动器 / 新电机的配置基准**。按 §4 步骤操作，结果必须满足 §5 验收标准。
> 本文件只写"做什么、做到什么值"；原因与排查过程见 [CAN通信与波特率调试记录](CAN通信与波特率调试记录.md)。

## 1. 硬件基线

| 项 | 基准 |
|---|---|
| 站号 | 轴1 = **1**，轴2 = **2**（驱动器旋码设置，主站不改） |
| 波特率 | **500 kbps**（拨码 SW3/SW4 对应档位，**上电生效**） |
| 终端电阻 | SW6 = **on** |
| CAN 接线 | CN6：1=CANH、3=CANL、5=GND；屏蔽层两端接 PE，不接 GND |
| STO | STO1+ / STO2+ 接 **24V**（短接） |
| 主电 | 48V 常上；`6079h` 母线电压 ≈ 47~48 V |
| STO/主电缺失的后果 | `6041h` 停在 `0x0400`，无法使能 |

| 轴 | 原点开关（近端，靠电机） | 限位开关（远端） |
|---|---|---|
| 1 | CN-1 **22 脚 DI5** | CN-1 **23 脚 DI6** |
| 2 | CN-2 **8 脚 DI5** | CN-2 **9 脚 DI6** |

方向约定：**正方向 = 面向出轴逆时针 = 滑台远离电机端**。

## 2. 驱动器参数基准（两轴相同）

| 对象 | 参数 | 基准值 | 说明 |
|---|---|---|---|
| `2023h` | Pr0.23 站号 | 轴1=1 / 轴2=2 | 旋码决定，只读核对 |
| `2024h` | Pr0.24 波特率码 | **2** | 2 = 500k，只读核对 |
| `2403h` | Pr4.03（SI4·DI4） | **0** | 空（不能与其它输入重复 HOME） |
| `2404h` | Pr4.04（SI5·DI5，原点输入） | **0x16** | HOME 回零基准 |
| `2405h` | Pr4.05（SI6·DI6，限位输入） | **0x01** | POT 正向禁止 |
| `2504h` | Pr5.04 驱动禁止设定 | **0** | POT 禁正向 / NOT 禁负向 |
| `2015h` | Pr0.15 绝对值编码器设置 | **0** | 增量模式（无电池盒；**掉电位置不保持**） |
| `1010h:01` | 参数保存 | 写 `0x65766173` | 修改参数后必须执行 |

只读基线（用于识别驱动器）：

| 对象 | 基准值 | 含义 |
|---|---|---|
| `1000h` | `0x00020192` | CiA 402 伺服 |
| `6502h` | `0x3002D` | 支持 PP/PV/PT |
| `608Fh:01 / :02` | `131072 / 1` | 编码器内部计数（**不是指令单位**） |
| `6091h` / `6092h` | **不存在** | 读任何子索引都回 abort `0x06020000`（2026-11-20 复测） |
| 换算 | **1 圈 = 10000 指令单位** | 运动实测：命令 2 圈 = 20000 指令单位，`6064h` 增量 19921 / 19997 |
| 位置单位 | 指令单位（非编码器计数） | `6064h` / `607Ah` / `6081h` 均用此单位 |

## 3. 主站通信基准

| 项 | 基准 |
|---|---|
| 接口 | SocketCAN，**经典 CAN**（非 FD），500k |
| 心跳 | 两轴各 1 Hz：`0x701`/`0x702`；`7F`=Pre-op，`05`=Operational |
| **使能前提** | **必须先发 NMT Start**（`0x000`：`01 <node>`），否则 `6041h` 恒 `0x0400` |
| 使能序列 | `6040h`：`0x0002` → `0x0006` → `0x0007` → `0x000F`（每步 250 ms，读回 `6041h`） |
| 使能确认 | `6041h`：`0x0631`（准备启动）→ `0x0633`（启动）→ `0x8637`（允许操作） |
| 断使能 | `6040h = 0x0000` |
| PP 触发 | 写 `607Ah` 目标 → `6040h = 0x001F` → 50 ms → `6040h = 0x000F` |
| 点动基准 | `6081h = 2000` 指令单位/s（1 圈/5 s），`6083h = 6084h = 2000` |
| 到位判定 | `6041h` bit10 = 1；`603Fh = 0` |
| 限位生效判定 | 以**实际运动被拒绝**为准（`6041h` bit11 不可靠） |

## 4. 新驱动器配置步骤（按顺序执行）

1. 按 §1 完成接线；确认 48V 主电、STO 24V、SW6=on
2. 上电；`can0` 以 500k 启动；确认两轴心跳 `0x701`/`0x702` 都在
3. SDO 读取并核对：`2023h`、`2024h`、`1000h`、`608Fh`、`6502h`、`6079h`（对照 §1/§2）
4. 按顺序写参数（**不可颠倒**）：
   - `2403h` ← `0`
   - `2404h` ← `0x16`
   - `2405h` ← `0x01`
5. 写 `1010h:01 = 0x65766173`（保存）
6. **断电重启**
7. 回读 `2403h`/`2404h`/`2405h`，确认仍为 `0 / 0x16 / 0x01`
8. 按压开关复验：近端 → `60FD` bit2（HOME）；远端 → `60FD` bit1（POT）
9. NMT Start → 使能序列 → 两轴各 PP 正转 1 圈 → 记录 `6064h` 增量与转向

## 5. 验收标准

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 通信 | 两轴心跳 1 Hz；无 BUS-OFF、无错误帧 |
| 2 | 站号/波特率 | `2023h` = 1/2；`2024h` = 2 |
| 3 | 参数保存 | `2403h`=0、`2404h`=0x16、`2405h`=0x01，断电重启后保留 |
| 4 | 输入复验 | 近端按压 → HOME 置位；远端按压 → POT 置位；释放即复位 |
| 5 | 使能 | NMT 后 `0x02→0x06→0x07→0x0F` 全通，状态依次 `0x0631→0x0633→0x8637` |
| 6 | PP 点动 | 1 圈位移 = **10000 指令单位**（±10），用时约 5 s，bit10 到位，`603Fh=0` |
| 7 | 方向 | 正方向 = 面向出轴逆时针 = 滑台远离电机 |
| 8 | 限位 | 限位按住时向该方向运动被拒绝（位移≈0）；反方向正常 |

## 6. 已知事项

- **指令单位换算**：1 圈 = 10000 指令单位（运动实测，不是读对象得来的）；`608Fh`（131072）仅编码器内部计数，**勿混用**；`6091h` / `6092h` 在本驱动器上不存在
- **`6064h` 空闲读数抖动 ±10 指令单位**（≈0.1% 圈），对位/对齐以物理标记为准
- **限位行为**：按住限位时，向该方向的 PP 运动被**静默拒绝**（不动、不报错、不丢使能）；反方向正常
- **`60FD` 验证用位**：bit0=NOT、bit1=POT、bit2=HOME、bit4~17=SI1~SI14
- **回零/标0**：`6098h=35` 标0 已实测（见 [原点标定与回零流程](原点标定与回零流程.md)）；**掉电不保持**，每次上电需回零
- **1M 波特率未验证可用**，当前基准为 **500k**
- **近端无硬限位**：负向越程保护由主站软限位 `607Dh` 负责
- 节点1 `Pr4.00`（SI1）= `0x83`（不在手册功能码表内，节点2 为 0），未处理
- 两轴曾在 250k/125k 出现波特率不一致；改拨码后**必须断电重启**再验证
