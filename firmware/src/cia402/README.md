# cia402/ — 设备层

CiA 402（DSP 402）语义封装：把一个 CANopen 节点表达成"一台伺服驱动器"。

## 结构

```text
cia402/
├── include/cia402/   公共头（设备描述、状态机命令、故障码）
└── src/              实现
```

## 职责

- 设备描述：站号、型号、对象清单、PDO 布局、缩放参数
- 402 状态机：使能 / 失能 / 快停 / 故障复位的命令与可观测状态
- 控制字 / 状态字语义封装
- 运行模式选择
- 故障码 → 上层可读的故障集

## 边界

- 只依赖 `canopen` 的公共头；SDO 用上游原语驱动（`canopen/sdo_client.h` 只交出
  客户端对象，不封装动作）；
- 不认识"轴"的机械含义，也不做轨迹与调度；
- 两轴是同一型号的两个节点 ⇒ 本层不含"双轴"特例。

## 已实现

| 能力 | 位置 |
|---|---|
| 状态字解析（纯函数）与状态名 | `src/cia402_state.c` |
| 使能序列：`6060=1`(PP) → `6040=06` → `07` → `0F`，每步等对应状态字 | `src/cia402.c` |
| 每拍推进一步（不阻塞）；单次 SDO 超时 200 ms 由上游报 abort | `src/cia402.c` |

未实现：失能 / 快停 / 故障复位（控制字 bit7）、PP 移动（`607A` + `4F/5F`）、
位置反馈（`6064`）、PDO 映射。
