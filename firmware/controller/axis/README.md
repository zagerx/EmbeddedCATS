# axis/ — 轴层

一个轴对应一个 CiA 402 设备实例，为业务层提供毫米单位的位置、速度、加速度和反馈。

## 职责

- 保存轴与节点的对应关系。
- 通过 `cia402/device.h` 提交配置、使能、运动、停止和急停请求。
- 汇总设备结果，向状态机提供 `axis_take_motion()` 等事实。
- 在 `mm ↔ pulse` 之间换算，并集中完成取整和饱和处理。
- 将设备反馈换算为 `mm`、`mm/s`。

## 边界

```text
statemachine → axis → cia402 → sdo_access
```

轴层不解释控制字、状态字或对象号，不直接访问 SDO/CAN，也不创建线程。多轴函数只是逐个转发请求；实际服务调度由宿主的调用方式决定。

机械参数位于 `config/cats_mech.h`，当前为编译期常量。
