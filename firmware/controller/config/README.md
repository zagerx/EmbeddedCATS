# config/ — 整机参数

两种参数，界线是"编译期固定还是运行期可调"。

| 文件 | 类型 | 内容 |
|---|---|---|
| `cats_mech.h` | 编译期宏（参与编译） | 机械换算：`PULSES_PER_REV` / `MM_PER_REV` |
| `pdo/*.h` | 编译期宏（参与编译） | 各节点的 PDO 布局（索引 / 子索引 / 位长 / 方向） |

为什么是宏：这些值是**这台机器的固件常量**（同型号驱动器 + 同规格滑台），
不是运行期可调项；写成宏后轴层直接拿来做换算，组合根不用再传参数，
也就没有"没配过就拒绕指令"的分支。

> PDO 布局的权威来源是厂商 EDS 与实机只读扫描结果。
> `cats_mech.h` 的当前取值是临时值，标定后只改这一处。
