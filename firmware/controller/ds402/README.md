# ds402/ — DS 402 标准知识（纯层）

**零依赖**：不 include `canopen`、不碰时间/线程/总线/单位。谁都能链它。

这里是"402 长什么样"的唯一定义处：状态枚举、命令、控制字/状态字位、
对象号、模式号，以及**状态转移函数**。

## 结构

```text
ds402/
├── include/ds402/
│   ├── types.h          状态/命令/模式枚举 + 控制字、状态字位
│   ├── od.h             对象号（全工程唯一出处）
│   └── state_machine.h  parse / cw_for / step
└── src/state_machine.c  转移表实现
```

## 三个函数

| 函数 | 回答什么问题 |
|---|---|
| `ds402_status_parse(sw)` | 这串状态字是什么状态？ |
| `ds402_cw_for(cmd)` | 这条命令的控制字是多少？ |
| `ds402_step(cur, target)` | 从当前状态要去目标状态，下一条命令是什么？ |

`ds402_step` 是这一层的价值所在：**需求表达为"走到目标状态"，不是"按 06→07→0F 走"**。
所以故障后复位、断使能后重新使能都自然成立，不用为每种起点写一套序列。
