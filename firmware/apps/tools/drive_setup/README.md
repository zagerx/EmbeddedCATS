# drive_setup/

`2LD2` 双轴驱动器的持久配置工具。**配置驱动器这件事只在脚本里做，固件不写这些参数。**

## 目标配置

| 项 | 内容 |
|---|---|
| TPDO1 | `1A00` = `6041`:16 + `603F`:16 + `6061`:8，`1800:01` = `0x180` + 站号，`1800:05` = 10 ms |
| TPDO2 | `1A01` = `6064`:32 + `606C`:32，`1801:01` = `0x280` + 站号，`1801:05` = 10 ms |
| 回零 | `6098h` = 21（原点开关法）、`6099h:01` = 2000、`6099h:02` = 500、`609Ah` = 2000 |

`6099h` 单位是指令单位/s，1 圈 = 10000；2000 = 0.2 圈/s。台架实测可用，实机按行程重算。

除上表以外一律不改：

- **禁止时间**（`1800:03` / `1801:03`）不写。节点 1 可写、节点 2 只读（中止 `0x06010002`），
  写它会让两轴行为不一致；出厂值 `2 ms` / `10 ms` 已经够用。
- **传输类型**（`180x:02`）保持 `255`。异步 TPDO 的事件定时器独立生效，不需要 SYNC。
- **TPDO3 / TPDO4** 不碰，保持出厂禁用。

## 为什么驱动器配置必须由脚本做

- 驱动器出厂时四路 TPDO 的 COB-ID 都是 `0x8000xxxx`（bit31 = 1，禁用），
  **不写一次 COB-ID 就永远不会有 TPDO 帧**。
- 回零的方法号与速度（`6098h` / `6099h` / `609Ah`）是驱动器持久参数，
  不属于每次回零的动作。

固件只负责运行时动作：`6040` 控制字、`6060` 切模式、`607A` / `6081` / `6083` / `6084` 指令值。

## 用法

```bash
# 配置 + 回读校验 + 听取 1.5 s
python3 drive_setup.py

# 只回读校验，不写任何配置（主站启动前自检）
# 为了能听到 TPDO，会把节点切到 Operational（断电重启后节点停在 Pre-operational）
python3 drive_setup.py --check

# 保存到驱动器（1010:01），掉电后不用重配
python3 drive_setup.py --save
```

默认**不保存**：驱动器掉电后回到出厂配置，需要重新执行本工具。
`--save` 会把配置写进驱动器（`1010h:01`），适合固定装机后使用。
台架两台驱动器已于 2026-11-23 用 `--save` 固化。

## 注意事项

- 运行前必须停掉 `cats_qt` / `master_probe` / `fake_drive`：配置会让节点进
  Pre-operational，正在运行的主站会立刻失去反馈。脚本会自己检查并拒绝执行（`--force` 可跳过）。
- 脚本假定总线上只有自己一个主站。结束前会把配置过的节点切回 Operational。
- 映射写入按 CiA 301 四步法（`1A0x:00 = 0` → 写条目 → `1A0x:00 = N`），
  只在当前值不符时才写，可反复执行。
