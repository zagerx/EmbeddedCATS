# tools/

辅助工具，不参与固件运行。

| 子目录 | 说明 |
|---|---|
| `od_scan/` | 只读对象字典扫描：遍历索引/子索引，记录存在性与 abort 码，导出 CSV |
| `fake_drive/` | CANopen 从站模拟器：无驱动器时在两路 PCAN 上模拟双轴节点（NMT + SDO） |

用途：有实物后第一步先跑 `od_scan`，得到对象字典快照，作为设备层配置与 PDO 布局的事实来源。
约束：`od_scan` **只读**，不发任何写请求。

`fake_drive` 是测试装置：用 PCAN 两个通道对连（`can0` 主站 / `can1` 从站）替代真实驱动器，
让主站在没有硬件时也能跑真实 CAN 报文；它的对象字典只是标准占位值，真机仍须用 `od_scan` 核对。
两者都只认 CAN 帧，不引用 `src/` 下任何模块。
